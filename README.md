# PDF Resume Analyzer for Java Backend Developer

Приложение для автоматического анализа резюме кандидатов на позицию Java Backend Developer с помощью AI (Polza AI).

## Особенности

- 📄 Загрузка PDF-файлов резюме (drag & drop)
- 🤖 Анализ с помощью Polza AI API (GPT-4o, Claude Sonnet, Gemini и др.)
- 📊 Подробная оценка навыков: Java, Spring, Backend, SQL, Docker и др.
- 🎯 Оценка соответствия уровню Junior/Junior+/Middle
- 📝 Сохранение истории анализов
- 💾 Экспорт результатов в Markdown и TXT
- 🌓 Поддержка темной темы

## Технологии

- **React** + **TypeScript** — основной фреймворк
- **Vite** — сборщик проекта
- **Tailwind CSS** — стилизация
- **shadcn/ui** — компоненты интерфейса
- **React Hook Form** + **Zod** — формы и валидация
- **Polza AI API** — API для анализа резюме

## Установка

```bash
npm install
```

## Настройка

1. Создайте файл `.env.local` в корне проекта:

   ```bash
   cp .env.example .env.local
   ```

2. Получите API ключ от [Polza AI](https://polza.ai) и добавьте его в `.env.local`:
   ```
   VITE_POLZA_API_KEY=sk-ваш-ключ-здесь
   VITE_POLZA_MODEL=openai/gpt-5.2
   VITE_API_URL=http://localhost:8080
   ```

### Получение API ключа Polza AI

1. Перейдите на [Polza AI](https://polza.ai)
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел API Keys
4. Создайте новый API ключ
5. Скопируйте ключ и добавьте в `.env.local`

## Запуск в режиме разработки

Перед запуском frontend убедитесь, что Spring Boot backend доступен по адресу
`http://localhost:8080` (либо укажите другой адрес в `VITE_API_URL`).

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

## Production build

```bash
npm run build
```

Для предпросмотра production сборки:

```bash
npm run preview
```

Каталог `dist/` предназначен для размещения на отдельном статическом хостинге.

## Использование

1. Откройте приложение в браузере
2. Перейдите на вкладку "Новый анализ"
3. Загрузите PDF-файл резюме (максимум 50 MB)
4. Введите API ключ (или используйте ключ из `.env.local`)
5. Выберите AI модель (рекомендуется: `openai/gpt-5.2`)
6. Нажмите "Анализировать резюме"
7. Дождитесь завершения анализа
8. Посмотрите результаты и используйте кнопки для копирования/экспорта

## Сохранение истории

После анализа вы можете сохранить результат в историю, нажав кнопку "Сохранить". История сохраняется в `localStorage` браузера и доступна на вкладке "История".

## Экспорт результатов

- **Копировать** — скопировать полный текст анализа в буфер обмена
- **.md** — скачать как Markdown файл
- **.txt** — скачать как обычный текстовый файл

## Безопасность API ключа

**ВАЖНО:** Поскольку это frontend-приложение, API ключ может быть виден в DevTools браузера. Для максимальной безопасности:

1. Не коммитьте API ключ в Git
2. Используйте `.env.local` файл для хранения ключа
3. Добавьте `.env*` в `.gitignore`
4. Для продакшена рассмотрите использование backend-сервера для проксирования запросов

## CORS и ограничения

Polza AI API поддерживает CORS, поэтому приложение может делать прямые запросы из браузера без дополнительной настройки прокси.

Frontend обращается к Spring Boot напрямую через `VITE_API_URL`. Если frontend и
backend работают на разных origin, Spring Boot должен разрешать origin frontend в
своей CORS-конфигурации. Этот репозиторий не управляет настройками CORS Spring.

## Решение проблем

### Ошибка "Failed to fetch"

- Проверьте правильность API ключа
- Убедитесь, что у вас есть интернет-соединение
- Проверьте, что выбранная модель поддерживает загрузку PDF файлов

### Ошибка "Пустой ответ от API"

- Убедитесь, что PDF файл не поврежден
- Проверьте размер файла (максимум 50 MB)
- Попробуйте другую модель

### Ошибка "API key обязателен"

- Убедитесь, что вы ввели API ключ в поле ввода
- Или добавьте ключ в `.env.local` файл
